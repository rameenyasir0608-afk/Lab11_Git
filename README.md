# Storage Estimator - Feature Version

## Purpose 
A simple Python program that estimates the total storage needed for the number of files.

## How to Run
1. Make sure Python is installed.
2. Open a terminal in this folder.
3. Run: 'py storage_estimator.py'

## Example
Input:
'''
How many files? 5
Average file size in MB? 2
'''

Output:
'''

Total storage needed: 10.0 MB
'''
